# Genshin resource icons

The three resource PNGs are served locally.

- `resin.png`: https://enka.network/ui/UI_ItemIcon_210.png
- `realm-currency.png`: https://enka.network/ui/UI_ItemIcon_204.png
- `daily-commission.png`: purple commission marker supplied by the user in `Pasted image 20261001143054.png` (replaces the previous white mission icon).

Game artwork belongs to HoYoverse. Stat symbols now use the game-style stat PNGs distributed by [EnkaCardData](https://github.com/DEViantUA/EnkaCardData/tree/main/assets/stats_icon). Their original `FIGHT_PROP_*.png` filenames are preserved in `stats/` (22 files, about 190 KB). CSS makes their monochrome artwork visible on the dark surface. Equipment and player namecard images use the existing restricted image proxy and their actual Enka metadata. Missing images leave readable labels and values.
